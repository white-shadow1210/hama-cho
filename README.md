# 販売・仕入れ管理

魚の卸販売のための、スマホで使える販売・仕入れ・加工の記録アプリです。
データは家族共有のGoogleスプレッドシートに保存されます。

- アプリ本体：`index.html`（GitHub Pagesで公開）
- スプレッドシート側：`gas/Code.gs`（Google Apps Script）

## はじめての設定（最初の1回だけ・約10分）

### 1. スプレッドシートを用意する
1. Googleドライブで新しいスプレッドシートを作る（名前は自由。例：「販売管理データ」）
2. メニューの **拡張機能 → Apps Script** を開く
3. 最初から入っている `function myFunction() {}` を消して、`gas/Code.gs` の中身をすべて貼り付ける
4. 上のほうにある `const PASSCODE = 'ここを合言葉に変える';` を、家族で決めた合言葉に変える
5. 💾 保存 → 上の関数の選択欄で **setup** を選び **▶ 実行**
   - 「承認が必要です」と出たら、自分のGoogleアカウントを選んで許可します
   - 「このアプリはGoogleで確認されていません」と出たら「詳細」→「（安全ではないページ）に移動」を選びます（自分で作ったプログラムなので問題ありません）
6. スプレッドシートに「品目・顧客・仕入れ・加工・販売」のシートができていればOK

### 2. ウェブアプリとして公開する
1. Apps Scriptの右上 **デプロイ → 新しいデプロイ**
2. 歯車アイコンから種類 **ウェブアプリ** を選ぶ
3. 次のユーザーとして実行：**自分**／アクセスできるユーザー：**全員**
4. **デプロイ** → 表示される「ウェブアプリのURL」（`https://script.google.com/macros/s/…/exec`）をコピー

> プログラムを書きかえたときは「デプロイ → デプロイを管理 → ✏️ → バージョン：新バージョン」で更新します（URLは変わりません）。

### 3. アプリにURLを入れる
- **おすすめ**：`index.html` の上のほうにある `const GAS_URL = '';` にURLを入れてGitHubに保存。
  家族の端末では、最初に合言葉を入れるだけで使えます。
- または：アプリの **⚙️管理 → 接続の設定** に、URLと合言葉を入れる。

### 4. スマホのホーム画面に置く（iPhone）
Safariでアプリを開く → 共有ボタン → **ホーム画面に追加**

## 公開する（GitHub Pages）
1. このリポジトリの **Settings → Pages**
2. Source を **Deploy from a branch**、Branch を **main / (root)** にして **Save**
3. 数分後に `https://white-shadow1210.github.io/hama-cho/` で開けます（このURLをスマホのホーム画面に追加）

## 品目のはじめの登録
⚙️管理 → 品目リスト → **標準の品目リストを入れる** で、価格表にある約36品目が入ります（バチマグロ・トンボなどの原料も含む）。
- 1個（パック）の重さを入れた品目は、加工のときに「正味の重さ」と「歩留まり」が自動で出ます。
- 🛒仕入・加工 → 加工 の下の「仕入れ量の目安」で、注文の数から必要な仕入れ量を逆算できます。

## 使い方のながれ

| 場面 | 画面 |
|---|---|
| 朝、市場で仕入れたとき | 🛒仕入・加工 → 仕入れ |
| 開き・切り身・パックにしたとき | 🛒仕入・加工 → 加工 |
| 配達先で売ったとき | 🚚販売 → お客さまをタップ → いつもの品目をタップ → 確認する → 登録する |
| 掛けの代金をもらったとき | ⚙️管理 → 未入金一覧 → 入金済 |
| 数が合っているか見るとき | 🛒仕入・加工 → 数の確認 |

- 電波が悪い場所で入力しても、端末に残り、つながったときに自動で送られます（右上に「未送信」と表示）。
- スプレッドシートは直接見たり集計したりして大丈夫です。**列の順番は変えない**でください（右側に列を足すのはOK）。

## 安全について
- アプリのURLとプログラムは公開されますが、**データはスプレッドシートにだけ**保存され、合言葉がないと読み書きできません。
- 合言葉は家族以外に教えないでください。変えたいときは `PASSCODE` を書きかえて setup をもう一度実行します（各端末で合言葉の入れ直しが必要です）。

## 注文メモ（予約）の使い方

| 場面 | 操作 |
|---|---|
| 前日に注文を受けたとき | 販売 →「📝 注文を受ける」→ 配達する日（今日・明日・あさって）→ お客さま → 品目と数 → 注文を受ける |
| 仕入れの前 | 仕入・加工 の一番上に「注文から見る仕入れの目安」。原料（マグロ・トンボなど）は歩留まりから必要量を計算。当日の＋α分は「上乗せ」に入れる |
| 配達の日 | 販売 →「📦 配達する注文」→「配達する」→ 内容を確認（数・値引き・掛けを調整）→ 登録。注文は自動で「配達済」になる |
| 数の確認 | 注文待ちの数が出て、注文に足りないときは警告が出る |

- 加工品（マグロ サクなど）と原料のひもづけは、管理 →「標準の品目を入れる」で自動設定（品目の編集でも変更可）。
- 売価が未設定の品目も名前はいつでも選べて、販売時に単価を手入力すると次回から自動で入ります。
- スプレッドシートに「注文」シートが自動で追加されます。**Code.gs を新しい内容に貼り替えて、新バージョンでデプロイしてください。**
